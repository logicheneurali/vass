# VASS — 音声アシスタントソフトウェア

## VASSとは

VASSはWindows、macOS、Linux向けの音声アシスタントです。音声コマンドに応答し、スクリプトを実行し、イベントやリマインダーを管理し、OpenAI互換APIを介してローカルまたはリモートAIと対話します。

**デフォルトのウェイクワード:** "Erika"

**主な機能:**
- Whisper（faster-whisper）による音声認識（適応ノイズフロア付き）
- Kokoro TTSによる自然な音声合成（4段階フォールバック）
- ローカルまたはリモートAI（llama.cpp、OpenAI、互換サーバー）
- 25以上の組み込み関数を持つVASScriptデスクトップ自動化
- イベント・スケジュール管理（GUIエディタ付き）
- 多言語音声タイマー（5つ同時）
- 21ツールのMCPサーバーによるAIオーケストレーション
- 自動分類・要約付き永続メモリ
- メッセージごとのアクション付き会話履歴ビューア
- 9言語サポート
- コンテキストオーバーフロー保護
- オーディオデバイス選択（入力/出力）
- 複雑なAIタスクのためのマルチターンツール呼び出し

## 要件

- **Python 3.13** 以上
- **AIサーバー** (llama.cpp または OpenAI互換) がシステムに既にインストール・設定済みであること。VASSは設定されていればllama.cppを自動起動できますが、**llama.cppのインストールやAIモデルのダウンロードは行いません**：別途入手する必要があります。
- **インターネット接続** (モデルのダウンロードとリモートAI用)
- ローカルAI用に **NVIDIA GPU 推奨** (CPUでも可能だが低速)
- 動作する **マイク**
- Windows 10+, macOS 12+, または最新のLinux

## インストール

### ガイド付きインストール

プロジェクトをダウンロードまたはクローンし、フォルダに入ってスクリプトを実行します:

```bash
cd vass
python install.py
```

> **注意：** ガイド付きインストールはVASSをセットアップしますが、**AIサーバーやモデルのインストールは行いません**。
> OpenAI互換サーバーが既に実行中である必要があります（llama.cpp、Ollama、LM Studio、Groq、OpenAI など）
> またはVASSの設定でllama.cppを構成してください（自動起動が可能です）。

**注意：** ガイド付きインストールはまだ実験的であり、すべてのシステムで動作するとは限りません。問題が発生した場合は、以下の手動インストールを使用してください。

ウィザードが以下をガイドします:
1. 言語の選択
2. 前提条件の確認 (Python 3.13+, pip)
3. インストール先フォルダ
4. パラメータ設定 (AI URL、モデル、ウェイクワード)
5. ファイルのコピー
6. Python仮想環境の作成 (.venv)
7. pip依存関係のインストール
8. settings.ini ファイルの作成
9. ランチャーの作成

### 手動インストール

```bash
# 目的のフォルダにファイルをクローンまたはコピー
cd VASS

# 仮想環境を作成
python -m venv .venv

# アクティベート (Windows)
.venv\Scripts\activate
# または (macOS/Linux)
source .venv/bin/activate

# 依存関係をインストール
pip install -r requirements.txt

# Playwright用Chromiumをインストール (ウェブ検索)
playwright install chromium

# settings.iniを作成 (サンプルのsettings.iniからコピー)
```

## 設定

`settings.ini` ファイルにはすべての設定が含まれています。最も重要なものは以下です:

| セクション | パラメータ | 説明 |
|---------|-----------|-------------|
| `[locale]` | `language` | 言語 (it/en/de/fr/es/pt/ja/ko/zh) |
| `[ai]` | `url` | OpenAI互換AIサーバーのURL |
| `[ai]` | `model` | AIモデル名 |
| `[ai]` | `system_message` | アシスタントの個性 |
| `[ai]` | `memory_tokens` | 最大メモリサイズ |
| `[wakeword]` | `wakeword` | ウェイクワード (デフォルト: erika) |
| `[wakeword]` | `sensitivity` | 検出感度 (0-1) |
| `[tts]` | `volume` | TTS音量 (0-1) |

VASSの実行中に設定が変更された場合、自動的に再読み込みされます。

## 日常的な使用

### 起動

`vass.bat` (Windows) または `vass.sh`/`vass.command` (macOS/Linux) をダブルクリックします。

またはターミナルから:
```bash
cd VASS
.venv\Scripts\python vass.py    # Windows
.venv/bin/python vass.py         # macOS/Linux
```

### ウェイクワード

ウェイクワードは、ユーザーが `settings.ini` ファイルで **設定変更可能** で、任意の単語または短いフレーズにできます。デフォルトは "**Erika**" です。

VASSがウェイクワードを検出すると、ビープ音を発してコマンドを受け付ける準備ができたことを知らせます。ビープ音の後に話してください。

例:
- *「Erika」*（ビープを待つ）、次に *「天気は？」*
- *「Erika」*（ビープを待つ）、次に *「ニュースを読んで」*
- *「Erika」*（ビープを待つ）、次に *「人工知能とは」*
- *「Erika」*（ビープを待つ）、次に *「おはようございます皆さんを英語に翻訳して」*
- *「Erika」*（ビープを待つ）、次に *「カルボナーラの作り方」*

### モード: チャットと文字起こし

VASSは2つのモードで動作し、ポップアップメニュー（メインボタンの右にある≡ボタン）から選択できます：

- **チャット** `[C]` — アプリケーションは音声コマンドを認識し、アクション（スクリプト、システムコマンド）を実行するか、AIと対話します。応答はTTSで読み上げられます。
- **文字起こし** `[T]` — コマンドを解釈する代わりに、VASSはウェイクワードの後（常にビープ音の後）にユーザーが発した内容を忠実に文字起こしします。テキストはアクティブなアプリケーションに貼り付けられ、VASSをテキストディクテーションシステムとして使用できます。

現在のモードはメインボタンに表示されます：チャットは `[C]`、文字起こしは `[T]`。最後に使用したモードは再起動時に復元されます。

### メモリモード

GUIメニューまたはメインボタンをクリックして:
- **Full** — AIがメモリサマリーを受け取ります
- **Limited** — AIが最近の履歴のみを受け取ります
- **None** — 履歴コンテキストなし

### 音声コマンド

コマンドは標準のINI形式で `commands.ini` に設定します。GUIエディタ（`python commands_editor.py`）でも編集可能です。各行は **フレーズ = アクション** のペアです：フレーズは認識するパターン（`{変数}` を含めることができます）、アクションは実行内容です。

```ini
[general]
{キーワード}を検索 = script:検索
{プログラム}を開く = start {プログラム}
オンライン検索 {escaped_terms} = start firefox "https://duckduckgo.com?q={escaped_terms}"
今何時 = script:時刻

[system]
システムをシャットダウン = shutdown /s /t 60
画面をロック = rundll32.exe user32.dll,LockWorkStation
```

#### マッチングの仕組み

1. **ファジー認識**：完全一致は必要ありません。VASSは発話されたフレーズをすべてのパターンと類似度アルゴリズム（`difflib`）で比較します。しきい値（デフォルト `0.75`、`settings.ini` で設定可能）を超える最も高いスコアのパターンが有効になります。

2. **変数 `{名前}`**：その位置で発話された単語をキャプチャします。例：*「猫をインターネットで検索」* と言うと、システムは `キーワード = "猫をインターネットで検索"` をキャプチャします。

3. **エスケープ変数 `{escaped_名前}`**：通常の変数と同様ですが、キャプチャされたテキストがURLエンコードされます（スペースが `%20` になります）。ウェブ検索に便利です。

4. **AIフォールバック**：どのコマンドも類似度しきい値を超えない場合、フレーズは自然言語応答のためにAIに送信されます。

#### カンマ代替（デカルト積）

カンマを使用して、各位置に複数の代替を指定できます。**スペース**は位置を区切り、**カンマ**は位置内の代替を区切ります。VASS は可能なすべての組み合わせ（デカルト積）を生成します。

```ini
# 単一位置：前置詞の代替
click the,on text {text}
```
3 パターンを生成: `click the text {text}`, `click on text {text}`, `click text {text}`。

```ini
# 2 位置：各位置に独自の代替
aa,xx bb,cc {var}
```
4 パターンを生成: `aa bb {var}`, `aa cc {var}`, `xx bb {var}`, `xx cc {var}` (2x2 = 4)。

```ini
# 混合：固定語 + 代替
turn on,off {device}
```
2 パターンを生成: `turn on {device}`, `turn off {device}` (`on` と `off` の間にスペースなし → 同じ位置)。

音声フレーズは生成されたすべてのパターンと比較されます。最良のファジーマッチが勝ちます。

#### アクションタイプ

| プレフィックス | 例 | 動作 |
|--------------|-----|------|
| `script:` | `script:検索` | `scripts/検索.vass` を実行。キャプチャされた変数は `$param1`, `$param2` などになります |
| `vasscript:` | `vasscript:イベント` | `script:` と同じ（代替プレフィックス） |
| URL | `https://...` | デフォルトブラウザで開く |
| コマンド | `shutdown /s` | システムコマンドとして直接実行 |

#### セクション名

`[general]` や `[system]` のようなセクション名は単なる整理用カテゴリであり、マッチングには影響しません。重要なのは **キー**（認識するフレーズ）です。

### VASScriptスクリプトの作成

GUIメニューからスクリプトエディタを開くか、以下を実行します:
```bash
python scripts_editor.py
```

すべてのスクリプトは拡張子 `.vass` で `scripts/` フォルダに配置します。

**認証**: 新規または変更されたスクリプトを実行する前に、VASSは許可を求めるポップアップを表示します。スクリプトはSHA-256ハッシュで検証され、認証後にスクリプトファイルが変更されると、権限は自動的に取り消され、次回実行時にポップアップが再表示されます。これにより、明示的な同意なしにスクリプトがマシン上で実行されることはありません。

完全な言語リファレンスについては [VASCRIPT_REFERENCE.md](../Allowed_root/VASCRIPT_REFERENCE.md) ファイルを参照してください。

### イベントとリマインダー

イベントは `events.json` ファイルで管理されます。音声リマインダーが1時間前（設定可能）に発行されます。

スケジュール（自動手順）は `schedule.json` にあり、TTS通知付きでコマンド実行をトリガーします。

## GUIインターフェース

- **メインボタン** — クリックで状態変更 (listening/paused)。マウスホイールで音量。ドラッグでウィンドウ移動。
- **音量バー** (緑色、上部) — 現在のTTS音量を表示
- **マルチステートバー** — コンテキストに応じてメモリ使用量、音量、またはスクリプトの進行状況を表示
- **自動フェード** — 非アクティブでフルスクリーン時にウィンドウが半透明になります

### ショートカット

| キー | アクション |
|-------|--------|
| `Ctrl+S` | 保存 (エディタ内) |
| ボタンクリック | 状態変更 |
| ボタン上でホイール | 音量調整 |
| 右クリック | コンテキストメニュー |
| スクリプト内の「読み上げ」ボタン | TTSでスクリプトを読み上げ |

## トラブルシューティング

> **重要:** このアプリケーションは使用するAIモデルに大きく依存します。効果の低いモデルやMCPツールの使用に適さないモデルは、機能を損なう可能性があります。

### VASSが起動しない
- Python 3.13+を確認: `python --version`
- `.venv` が存在し依存関係が含まれていることを確認
- `debug.log` でエラーを確認

### マイクが動作しない
- マイクが接続され、他のアプリで使用中でないことを確認
- マイクのシステム権限を確認
- Windowsの場合: 設定 → プライバシー → マイク

### AIが応答しない
- AIサーバーが `http://127.0.0.1:8080/v1` で実行中か確認
- `settings.ini` の `[ai] url` を確認
- llama.cppを使用している場合、モデルが `models/` フォルダに存在するか確認

### OCRが画面上のテキストを認識しない
- 画面上のフォントサイズまたはコントラストを上げてください
- EasyOCRは大きなフォントと高いコントラストで最適に動作します
- OCR言語は設定されたロケールに自動的に適応します
