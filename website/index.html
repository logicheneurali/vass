VASS — Voice Assistant Software

Your private AI voice assistant, fully local and offline

⬇ Download v0.6.0 📖 Documentation

Features

Voice Control

Always-on "Vass" wake-word, automatic noise pause, transcription mode. Multilingual support.

Local AI

llama.cpp model running on your hardware. Permanent memory with auto-tagging. No data leaves your PC.

Google Integration

Sync Google Calendar and Gmail. Scheduled events and tasks. Google Home & Assistant support.

Automation

VASScript for custom workflows. Screen OCR, simulated mouse & keyboard. MCP tools for AI agents.

Screenshots

Compact interface — always visible, never intrusive

Interactive tag map — force-directed bubble chart

Permanent memory — conversations, emails, events sorted by tags

Info Panel — AI response links and notifications (Gmail, events, timers)

VASScript editor — custom automations with OCR, click, keyboard
